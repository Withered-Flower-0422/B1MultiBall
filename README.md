## Requirements

- Ballex Alpha 1.7.0 or later
- BME4 Alpha15 or later

## Usage

1. Unpack `MultiBall.package` in BME4.
2. Add the `MultiBall` item into the scene.
3. Then you can use the MultiBall related items in BME4 like official items.

## Features

Basically the same as the official MultiBall system of legacy Ballex².
